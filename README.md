# **To-Do List**

## **Description**

A to-do app built with Webpack

From The Odin Project's [curriculum](https://www.theodinproject.com/lessons/node-path-javascript-todo-list).


## Live Demo
[Here](https://badger-cmyk.github.io/ToDoList/)

## Built With
- HTML
- CSS
- JavaScript
- Webpack

## What I Learned
- How to set up Webpack to bundle web files
- How to configure Wepack loaders to handle different file types including CSS, images and fonts 
- How to work with ES6 modules and separate different concerns into different files
- How to dynamically manipulate the DOM
- How to use event delegation so events trickle down to children nodes from parent nodes
- How to write npm scripts to handle different tasks
- How to use two different config files and servers; one for dev and the other for production
- How to use other external libraries in your code, specifically [date-fns](https://github.com/date-fns/date-fns) to format dates
- How to use the localStorage object to allow for the persistence of data in the browser
- How to use JSON.stringify() and JSON.parse() to save and retrieve data from localStorage
- How to deploy a Webpack project to GitHub Pages
